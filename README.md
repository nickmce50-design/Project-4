Project 4 : Hardened
Developer: Nicholas McEntee

Hardened is a 2d Platformer where the main character, the knight, has to navigate his way around traps and tricks in order to save the Princess. Follow his short journey to see if he is able to defeat the dragon and save the princess.

Play Game on Itch.io: https://nickmce50-design.itch.io/hardened?secret=54eKTOWDXSKE16gZPAgjDJpw8kM

- The platforms are very violent once the path finishes, It looks odd and wasn't intended. Don't know if its something I should fix or keep in the game
- Can't go through the door twice, it crashes the game.
