CAVE+GEN

Side-view procedural cavern generator with postprocessing

What this is

This project generates images showing a side view of the cave. It was created while I was messing around with different assets for the background of one of my projects.

Keys

R new cave S save PNG 1–4 presets 5 random Tab cycle panels I this panel Esc close

The panels

  • Look — presets, the palette, the dither.
  • Shape — cavern generation parameters.
  • Light — light source parameters.
  • Canvas — canvas size and export parameters.

Palettes

Import straight from lospec.com with a slug or a full URL, or paste a hex list.

Additional checkboxes allow you to Sort by luminance, and Ramp curve changes the value-to-colour mapping when a palette's steps are unevenly spaced. You can also name your palette to load next time you generate a cave.

Saving a setup

The Canvas panel exports all parameters as one JSON file. Use it to pass the configs around, or save with the image. Reset returns everything to the defaults.
