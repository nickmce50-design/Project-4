FANTASY DUNGEON - COMPLETE KIT 64  ·  by Woshi Studio
=====================================================
A true game-in-a-box: characters, bosses, enemies, NPCs, weapons, armor, items,
VFX, UI, props, farm & nature, crafting stations, and tiles - one cohesive style.
Game-ready for Godot, Unity, GameMaker.

============================ CHARACTERS ============================
Fully animated: Idle / Walk / Attack / Death, in 3 directions each.
Attacks READ: melee heroes SWING their weapon (with a slash flash), archers loose
an arrow, mages cast a projectile. Mirror the "side" sheet for left-facing.
Frames: idle/walk/attack=4-5, death=6.

  HEROES (64px - distinct silhouette + build + armor + signature weapon)
    Warrior, Rogue, Mage, Cleric, Ranger, Barbarian
  NPCs (64px) : Bartender, Blacksmith, Merchant, Guard, Villager, King
  ENEMIES (64px, 3-dir) : Orc, Dark Knight, Slime, Bat
  BOSSES (96px - larger, menacing) : Stone Golem, Slime King, Cave Troll

============================ VFX (64px, animated) ============================
  slash, hit spark, heal, level-up, magic bolt, explosion, poison cloud
